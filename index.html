⚙️ 全局配置

多台 VPS 共用
每台 VPS 可填写已在 Cloudflare 绑定该 VPS IP 的域名；留空使用上方根域名。证书域名和 WS Host 使用这个域名，优选 IP/域名只用于 WS 节点的连接地址。单机一键命令会携带这里填写的 API Token。批量 SSH 部署会在本机终端提示输入 Token。
HTTP-01 不需要 Cloudflare Token，但每台 VPS 都必须能通过同一证书域名完成 HTTP 验证。多 VPS 使用同一域名时更建议 Cloudflare DNS-01。

部署方式

单机一键安装：填完本页参数，点击生成并复制命令，直接粘贴到目标 VPS 的 root 终端即可。每次生成安装命令时，都会同步生成对应的卸载命令。已有管理安装会自动覆盖升级并保留现有配置；批量 SSH 部署也支持覆盖升级。

🧹 对应卸载命令

与最近生成的安装命令对应
生成单台安装命令后，这里会同步显示该 VPS 的卸载命令；生成批量部署脚本后，这里会生成对应台数的批量卸载脚本。单台命令在目标 VPS 的 root 终端执行；批量脚本在本机运行并按提示输入 SSH 目标。
卸载属于破坏性操作：会停止 sing-box 服务，删除 /etc/sing-box 管理数据和证书副本、管理脚本及其安装的 sing-box 软件包。不会删除 /root/.acme.sh、系统依赖包、sing-box 系统用户/组、系统防火墙规则或云厂商安全组。执行前请确认连接的是正确的 VPS。
本工具为静态前端配置生成器；表单不会发送到网页服务器。Cloudflare Token 仅在本地浏览器中参与命令生成，但会被编码进单机安装命令。卸载命令不包含 Token 或安装配置。请妥善保管生成的命令。实际部署结果以 VPS 上 sing-box 配置检查和服务状态为准。
