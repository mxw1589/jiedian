五种协议 TCP 端口（留空自动分配）

端口留空时由 VPS 自动分配可用端口。WS + TLS 自动从 Cloudflare 支持的 HTTPS 端口 2053、2083、2087、2096、8443 中选择；其余协议自动使用 10000–65535。若手动端口已被其他程序占用，脚本会自动改用该协议支持范围内的空闲端口。NAT VPS 必须使用服务商已分配并映射的端口。
随机分配会避开本机已监听的 TCP 端口。安装后请放行最终显示的端口。NAT VPS 若自动换端口，还必须在服务商面板同步添加新公网端口到本机同号端口的映射，否则节点无法从公网访问。

🧰 不通过 HTML 的 SSH 直接安装

交互式安装向导
如果不想使用上面的网页配置，可以直接 SSH 登录 VPS，以 root 身份执行下面命令。Shell 脚本会在终端逐项询问证书方式、域名、端口等参数。
set -eu
if [ "$(id -u)" -ne 0 ]; then
  echo '请先以 root 登录，或先执行 sudo -i。'
  exit 1
fi
if ! command -v curl >/dev/null 2>&1; then
  if [ -f /etc/alpine-release ]; then
    apk add --no-cache curl
  elif [ -f /etc/debian_version ]; then
    apt-get update
    apt-get install -y curl
  else
    echo '仅支持 Debian / Ubuntu 和 Alpine。'
    exit 1
  fi
fi
curl -fsSL 'https://raw.githubusercontent.com/mxw1589/jiedian/main/sb-manager-debian-alpine.sh' -o /tmp/sb-manager-debian-alpine.sh
chmod 700 /tmp/sb-manager-debian-alpine.sh
/tmp/sb-manager-debian-alpine.sh
直接安装不需要打开 HTML，也不需要把 Cloudflare Token 写进命令。选择 Cloudflare DNS-01 时，脚本会在 SSH 终端中安全提示输入 Token。

🗑️ 卸载 sing-box 管理器

root 权限 · 立即执行
SSH 登录需要卸载的那台 VPS，切换到 root 用户后执行：
/usr/local/sbin/sb-manager uninstall

卸载范围

将删除：/etc/sing-box 管理目录及其中的配置和证书副本、/usr/local/sbin/sb-manager、sing-box 服务文件、证书重载钩子，以及本脚本安装的 sing-box 软件包。脚本还会清理自己创建的 BBR 持久化配置，并尝试恢复安装前的 TCP 拥塞控制参数。
不会删除：/root/.acme.sh、系统依赖包、sing-box 系统用户/组、系统防火墙规则、云厂商安全组或其他 cron 任务。
卸载命令会立即执行，不再要求输入大写确认文本。执行前请确认 SSH 连接的是正确 VPS，并备份仍需保留的节点信息和配置。
本工具为静态前端配置生成器；表单数据只在当前浏览器中处理。实际部署结果以 VPS 上 sing-box 配置检查和服务状态为准。
