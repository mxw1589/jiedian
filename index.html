Reality 参数
TLS 证书（仅 AnyTLS / Naive / 直连 WS 需要）
填写证书要覆盖的完整域名，并将其 A/AAAA 记录解析到 VPS。AnyTLS、NaiveProxy 和直连 WS 共用此值；直连 WS 的 Host 默认也用它。不填优选域名/IP；建议与 Tunnel 绑定域名不同。
证书自动使用 Let's Encrypt HTTP-01 签发和续期，不需要 Cloudflare 根域名、DNS API Token 或 Zone ID。请确保域名解析到 VPS，且公网 TCP 80 可访问。
本机端口 留空：优先沿用上次端口
留空由 VPS 选择空闲端口。若 NAT 服务商指定了内网监听端口，请在对应项填写该端口；公网映射需另行配置。
系统类型和 CPU 架构无需填写：安装脚本会自动识别 Debian / Alpine、可用 CPU 架构，并选择 systemd 或 OpenRC。Naive 服务端由 sing-box 内置支持，自动确保版本不低于 1.13.0；VPS 不需要额外安装独立 Naive 服务端核心。

Cloudflare Argo Tunnel 路由设置（仅选择 Argo 时需要）
  1. Cloudflare Zero Trust → Networks → Tunnels，创建或选择 remotely-managed 固定 Tunnel，不要使用临时 Quick Tunnel。
  2. 在 Tunnel → Public Hostnames / Routes 添加上面填写的 Public Hostname，Service Type 选 HTTP，Service URL 填写安装完成后终端显示的 http://127.0.0.1:本机WS端口。
  3. 复制 Add a replica 中完整的 Tunnel Token，粘贴到页面的 Token 输入框。
  4. 确认 Tunnel 状态为 Healthy。Argo 模式客户端公网端口固定为 443，不需要 NAT 公网入站端口或 VPS 源站 TLS 证书。

NaiveProxy 客户端配置说明（Linux）
VPS 运行 sing-box Naive 入站。节点信息刷新时会生成 /etc/sing-box/naive-client.json（TCP）和 /etc/sing-box/naive-client-uot.json（sing-box UDP-over-TCP v2）。标准 naive+https:// 分享链接使用证书域名作为 URI 主机 / TLS SNI，不使用 IP + 非标准 sni 查询参数。域名应使用 DNS only 并直接解析到 VPS；普通 Cloudflare 橙云代理不能当作任意 Naive TCP 端口的通用转发。原生 NaiveProxy 主要承载 TCP；UDP-over-TCP 需要客户端也支持 sing-box UoT。Linux sing-box 客户端必须使用包含 libcronet.so 的兼容构建，Windows 需要 libcronet.dll；不是所有 sing-box 构建都含 Naive 出站。NAT 公网映射端口若不同于 VPS 内部监听端口，客户端配置中的 server_port 应改为公网映射端口。
