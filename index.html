② 全局配置

安全提示：oap 不只是放行代理端口。上游脚本会把 IPv4 iptables 的 INPUT / FORWARD / OUTPUT 默认策略设为 ACCEPT，并清空整个 filter 规则表；可能暴露 SSH、数据库等服务并删除现有防火墙规则。通常请保持关闭。

③ 订阅链接设置

启用后，官方脚本会生成 Clash / Mihomo、Sing-box 和聚合单节点订阅。订阅由普通 HTTP 提供，访问密码放在 URL 路径中；不要公开分享订阅地址。

④ Argo 临时 / 固定隧道 CDN

临时隧道：只选择 Argo 主协议，CF 域名和 Token 都留空。固定隧道：必须同时填写域名和 Token。VLESS XHTTP-Enc 的 Argo 模式仅支持固定隧道。

⑧ 每个输入项需要填写什么

协议端口

先勾选协议，再在右侧填端口。留空由脚本随机分配；手动填写请确认端口空闲。

UUID 密码

通常留空即可，服务器自动生成。只有需要固定 UUID、复用旧节点身份时才手动填标准 UUID。

Reality 域名 reym

只在 Reality 相关协议启用时填写；留空默认 apple.com。自定义时填写域名，不要带 https:// 或端口。

CDN 优选 IP 域名 cfip

只用于 VMess WS、VLESS XHTTP/WS-Enc、XHTTP TLS-TCP/UDP 的 CDN 优选连接地址。填 1–2 个域名，以空格分隔；留空使用上游默认的 www.shopify.com 和 icook.tw。

域名 / IP 证书 TLS alns

默认关闭，相关协议使用自签 TLS。若服务器尚无 /root/ygkkkca/private.key，上游会调用 Acme-yg 尝试申请域名/IP 证书；申请失败会回退到自签证书。

HY2 端口跳跃 hyjpt

仅 Hysteria2 使用。示例：123:456 789，表示 UDP 端口范围 123–456 和单端口 789。注意：上游会清空 IPv4/IPv6 NAT PREROUTING 规则后再添加跳跃规则；Docker 或自定义端口转发环境不要随意启用；若范围覆盖 TUIC、XHTTP-UDP、SS2022 或 SOCKS5 端口，也可能导致对应节点 UDP 流量被转发到 HY2。

CF 回源域名 cdnym

只用于 VMess WS、VLESS XHTTP-Enc、VLESS WS-Enc 的 CDN 回源 Host。没有 CDN 回源需求就留空。

WARP 出站 warp

默认服务器本地 IP。其余 15 种组合分别控制 Sing-box 与 Xray 的 IPv4 / IPv6 WARP 出站。

IP 导出 ippz

默认自动；选择 4 只导出 IPv4 节点，选择 6 只导出 IPv6 节点。

开放所有端口 oap

强烈建议关闭。开启会将 IPv4 iptables 默认策略设为 ACCEPT 并清空 filter 规则表，可能删除现有防火墙规则并暴露其他服务。

订阅 sub / subid / subpt

开启后提供 Clash/Mihomo、Sing-box 和聚合订阅。subid 是 URL 路径密码，subpt 是 HTTP 服务端口；两项可留空自动生成。订阅使用普通 HTTP，请勿公开链接。

Argo agn / agk / agqc

临时隧道不填域名和 Token；固定隧道两项必须同时填写。agk 粘贴完整 eyJ... Token。agqc 默认 HTTP/2（TCP），可选 QUIC（UDP）。
