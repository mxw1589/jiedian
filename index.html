Reality 参数
TLS 证书（仅 AnyTLS / Naive / 直连 WS 需要）
填你管理且证书要覆盖的完整域名；在 Cloudflare DNS 中配置该名称的 A/AAAA 等记录，使其指向 VPS。AnyTLS、NaiveProxy 和直连 WS 共用此值；直连 WS 的 Host 默认也用它。不填优选域名/IP；建议与 Tunnel 绑定域名不同。
例如区域为 example.com、证书要签给 direct.example.com，则两栏分别填写。如果证书就签给区域本身，只填这里，上方证书域名留空即可。
DNS API Token 与上面的 Tunnel Token 是两种不同凭据。只有选择 DNS-01 时才需要这组 Cloudflare 字段。
HTTP-01 不需要 Cloudflare Token，但要求证书域名解析到 VPS，且公网 TCP 80 可访问；NAT VPS 通常更适合 DNS-01。
本机端口 留空：优先沿用上次端口
留空由 VPS 选择空闲端口。若 NAT 服务商指定了内网监听端口，请在对应项填写该端口；公网映射需另行配置。
Cloudflare WARP 域名分流 可选
填写你自己的 WARP WireGuard 配置参数。域名按行或逗号分隔；填写根域名后，该域名及其所有子域名都会走 WARP。指定域名的 DNS 查询也会使用 Cloudflare DoH 并经 WARP 发送；其他域名继续使用系统 DNS 和 direct。此功能使用 sing-box 内置 WireGuard endpoint，不创建系统级全局 VPN 路由。
PrivateKey、IPv4 Address、IPv6 Address 和 Reserved 都可能因 WARP 配置而不同，必须从你自己的 WireGuard 配置复制；尤其 Reserved 不要直接照抄示例。IPv6 留空时，WARP 规则会先按 IPv4 解析目标域名，只把 IPv4 连接送入 WARP。VPS 必须允许向 Endpoint 的 UDP 端口出站。
已有 VPS：网页同步时未勾选 WARP 会移除原 WARP 分流；要保留请重新勾选并填写原参数。客户端应把域名交给代理服务器处理，不要先在本地解析成 IP，否则服务端无法按域名匹配。
系统类型和 CPU 架构无需填写：安装脚本会自动识别 Debian / Alpine、可用 CPU 架构，并选择 systemd 或 OpenRC。Naive 服务端由 sing-box 内置支持，自动确保版本不低于 1.13.0；VPS 不需要额外安装独立 Naive 服务端核心。

Cloudflare Argo Tunnel 路由设置（仅选择 Argo 时需要）
  1. Cloudflare Zero Trust → Networks → Tunnels，创建或选择 remotely-managed 固定 Tunnel，不要使用临时 Quick Tunnel。
  2. 在 Tunnel → Public Hostnames / Routes 添加上面填写的 Public Hostname，Service Type 选 HTTP，Service URL 填写安装完成后终端显示的 http://127.0.0.1:本机WS端口。
  3. 复制 Add a replica 中完整的 Tunnel Token，粘贴到页面的 Token 输入框。
  4. 确认 Tunnel 状态为 Healthy。Argo 模式客户端公网端口固定为 443，不需要 NAT 公网入站端口或 VPS 源站 TLS 证书。

Cloudflare WARP WireGuard 参数如何填写
从你自己的 Cloudflare WARP WireGuard 配置中读取参数：PrivateKey 对应私钥；Address 中的 IPv4 / IPv6 地址分别填入两个地址框；Reserved 对应三个十进制字节；Endpoint 的 IP 和端口填入 Endpoint 与 UDP 端口。页面内置的是普通消费者 WARP 的 WireGuard 公钥。不要把私钥发给他人。
WARP 域名规则同时匹配精确根域名和以该域名结尾的子域名：例如填写 example.com，则 example.com、www.example.com、api.example.com 都走 WARP。脚本会先嗅探 TLS SNI / HTTP Host，再解析目标域名；IPv6 地址留空时按 IPv4-only 解析，只有 AAAA 记录的目标会连接失败，不会回退到 direct。
VPS 命令菜单：添加 / 删除 / 按协议修改参数
登录 VPS 执行 /usr/local/sbin/sb-manager：菜单 18 增量添加未安装协议；菜单 19 删除指定协议（需输入 DELETE 确认）；菜单 20 先选择协议，再修改 SNI / TLS 域名、WS 优选 IP、Cloudflare Zone 或 Argo Public Hostname、端口和协议凭据。 TLS 证书域名在 AnyTLS、NaiveProxy、直连 WS 之间共享；Reality SNI 在两种 Reality 协议之间共享。菜单会显示这些共享关系和每种协议的必填 / 可选值。密码留空保持原值，输入 - 可随机生成；端口留空自动分配。
NaiveProxy 客户端配置说明（Linux）
本项目在 VPS 上运行的是 sing-box 的 Naive 入站，不需要另装独立 Naive 服务端核心。启用 NaiveProxy 后，管理器会在节点信息刷新时生成 /etc/sing-box/naive-client.json，供 sing-box 1.13.0+ Linux 客户端使用。若某个图形客户端提示找不到 Naive 核心，那是客户端自身的核心路径设置，与 VPS 服务端核心是否安装是两回事。NAT 公网映射端口若不同于 VPS 内部监听端口，客户端配置中的 server_port 应改为公网映射端口。
