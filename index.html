⚙️ 全局配置

多台 VPS 共用
多 VPS 建议给每台服务器配置不同的 TLS 子域名（例如 vps1.example.com、vps2.example.com），在 VPS 卡片的“TLS 域名覆盖”中填写；全局 TLS 域名仅作默认值。这样可避免多台机器反复为同一个域名申请重复证书。API Token 不在网页中填写。单机命令会在 VPS 上安全提示输入；批量部署脚本只在你本机运行时提示一次，并通过 SSH 输入流传送，不会写入 GitHub Pages。
HTTP-01 不需要 Cloudflare Token，但每台 VPS 都必须能通过同一证书域名完成 HTTP 验证。多 VPS 使用同一域名时更建议 Cloudflare DNS-01。

部署方式

单机：复制命令到目标 VPS 的 root SSH 终端。批量：下载生成的 deploy-multi.sh，在你自己的 Linux / macOS / WSL 电脑运行，并使用 SSH 密钥登录每台 VPS。
