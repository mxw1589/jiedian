③ 按所选协议填写参数

无关字段自动禁用
只有选择需要直连公网的协议时才启用。Argo-only 安装不需要填写源站公网 IP。

源站 TLS 证书（AnyTLS / Naive / 直连 WS / XHTTP + ECH 需要）

这是 DNS-01 证书 API Token，与上方 Argo Tunnel Token 是两种不同凭据。只在需要源站证书时启用。
HTTP-01 要求证书域名解析到 VPS，且公网 TCP 80 可访问。NAT VPS 通常不适合使用此方式。

VLESS + XHTTP + ECH（独立 Xray-core）

这是外层 ClientHello 暴露的公开名称，不是证书域名。服务器会生成 ECH Server Keys 和客户端 ECH Config List。
ECH 客户端需要使用安装后输出的 ECH Config List。XHTTP + ECH 必须直连 VPS 的 Xray TLS 入站；DNS 记录设为 DNS Only（灰云），不要把此域名代理到普通 CDN。NAT VPS 需将公网 TCP 端口映射到 XHTTP 本机端口。

⑤ Cloudflare Tunnel（Argo）必须完成的路由设置

Argo 模式
  1. Cloudflare Zero Trust → Networks → Tunnels，创建或选择一个 remotely-managed Tunnel。
  2. 在 Tunnel → Public Hostnames / Routes 添加主机名，Service Type 选 HTTP，Service URL 填写安装后终端显示的 http://127.0.0.1:本机WS端口。
  3. 从 Tunnel 的 Add a replica 安装命令中复制 eyJ... Token，粘贴到上面的 Tunnel Token 输入框。
  4. 确认 Tunnel 状态为 Healthy。Cloudflare 会将 HTTPS/WS 流量经 Tunnel 转发到 VPS 的本机 HTTP WebSocket 入站。
Argo 模式不需要 NAT 服务商提供公网入站端口，也不需要 VPS 为 WS 节点申请证书；Cloudflare 边缘负责客户端 TLS，cloudflared 通过出站连接回源。确保 VPS 可以访问 Cloudflare Tunnel 所需的出站网络（默认连接端口 7844）。

不通过 HTML 的 SSH 直接安装

交互式选择协议
以 root 登录 VPS 后执行。脚本会在终端询问需要安装的协议及其必需参数。
set -eu
if [ "$(id -u)" -ne 0 ]; then echo '请先以 root 登录，或先执行 sudo -i。'; exit 1; fi
if ! command -v curl >/dev/null 2>&1; then
  if [ -f /etc/alpine-release ]; then apk add --no-cache curl
  elif [ -f /etc/debian_version ]; then apt-get update && apt-get install -y curl
  else echo '仅支持 Debian / Ubuntu 和 Alpine。'; exit 1; fi
fi
curl -fsSL 'https://raw.githubusercontent.com/mxw1589/jiedian/main/sb-manager-debian-alpine.sh' -o /tmp/sb-manager-debian-alpine.sh
chmod 700 /tmp/sb-manager-debian-alpine.sh

卸载 sing-box 管理器

root 权限
/usr/local/sbin/sb-manager uninstall
卸载会删除本脚本管理的 sing-box / Xray 配置、服务、ECH 密钥及 Cloudflare Tunnel 专用服务和 Token 文件。若 cloudflared 二进制由本脚本下载，也会删除；系统中原本存在的 cloudflared 二进制不会删除。不会删除 Cloudflare 控制台中的 Tunnel、DNS 记录或服务商端口映射。
