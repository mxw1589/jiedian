# v1.1.0 预检失败：依赖区空行兼容修复

## 已确认的现象

在一个报告的 Sing-box-yg `v26.4.11` 安装中，源码锚点检查结果为：

- STTY：1 次匹配；
- 依赖区：0 次匹配；
- Argo：1 次匹配；
- 补丁标记：0 次匹配。

该安装的依赖区相关行是：

```bash
touch sbyg_update
fi

if [[ $vi = openvz ]]; then
```

v1.1.0 只接受 `fi` 后立即出现 OpenVZ 判断的布局，因此因为一个空行而拒绝。

## v1.2.0 的修复方式

v1.2.0 只放宽这一处结构锚点：允许 `fi` 与 OpenVZ 判断之间出现零行或多行空白行。它仍然要求：

1. `touch sbyg_update` 后面紧接关闭 `fi`；
2. 后续第一个非空行必须是预期的 `if [[ $vi = openvz ]]; then`；
3. 整个文件中此结构只能匹配一次；
4. STTY 和 Argo 两个锚点仍然必须分别唯一匹配。

如果中间有 `echo`、变量赋值或其他命令，或者出现多个候选结构，补丁仍会拒绝修改。

## 运行方式

先只读预检：

```bash
python3 patch_sb.py --check
```

预检通过后再执行：

```bash
bash install.sh
```

修复前仍会备份 `/usr/bin/sb`，修复后执行 `bash -n`；语法检查失败会恢复备份。

## 验证边界

此修复依据用户提供的 v26.4.11 源码诊断结果和对应的脱敏结构片段制作。自动测试覆盖该空行布局、无空行、多空行、CRLF、重复锚点和中间存在非空语句等情形。没有声称在所有上游分支或所有定制版本上验证通过。
